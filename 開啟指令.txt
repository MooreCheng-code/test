==============================================================================
企業破產風險預測系統 (Bankruptcy Early Warning System) - 啟動與操作指令指南
==============================================================================

【最推薦：一鍵批次檔（滑鼠雙擊即可執行）】
- 一鍵啟動_全部服務.bat  : 同時開啟 Streamlit 前端與 FastAPI 後端，並自動打開瀏覽器
- 一鍵啟動_僅Streamlit.bat : 僅開啟 Streamlit 視覺化前端互動介面
- 一鍵關閉系統.bat         : 一鍵安全關閉 Port 8000 與 8501 之背景服務

------------------------------------------------------------------------------
手動命令列執行（PowerShell 或 CMD）：
請先進入專案目錄：
cd /d "d:\test-master\test\bankruptcy"

------------------------------------------------------------------------------
一、啟動 Streamlit 視覺化互動系統 (推薦主要介面)
------------------------------------------------------------------------------
指令：
python -m streamlit run app/app.py --server.address localhost

說明：
- 執行後於瀏覽器開啟 http://localhost:8501
- 涵蓋 5 大分頁：風險總覽預警、診斷與 What-if 模擬、模型原理與指標、公約免責聲明、批次評估與示範 (Tab 5)

------------------------------------------------------------------------------
二、啟動 FastAPI 高效能批次與解釋 API 服務
------------------------------------------------------------------------------
指令：
python -m uvicorn api.main:app --host 127.0.0.1 --port 8000

說明：
- 服務啟動於 http://127.0.0.1:8000
- 互動式 Swagger API 規格文檔位於 http://127.0.0.1:8000/docs
- 核心端點：
  * GET  /health (健康檢查)
  * GET  /model-info (模型版本與支援工作點)
  * POST /score/json (JSON 批次評分，上限 1,000 筆)
  * POST /score/batch-csv (大型 CSV 批次串流評分，10MB 上限)
  * POST /explain/case (單筆特徵 TreeSHAP 與線性歸因)

------------------------------------------------------------------------------
三、執行獨立 CLI 批次評估工具 (score_new_data.py)
------------------------------------------------------------------------------
指令範例：
python score_new_data.py --input <path_to_input.csv> --output <path_to_output.csv> --model E_A --operating-point R90 --allow-missing --sort-by-risk

說明：
- 支援模型：E_A (預設)、M3、M4、M1
- 支援工作點：R80、R90 (預設)、R95、R100
- 缺失值旗標：--allow-missing (啟用訓練集中位數自動補值)；未啟用時維持舊版相容性。

------------------------------------------------------------------------------
四、執行全套自動化測試與產物完整性校驗
------------------------------------------------------------------------------
指令：
python -m pytest -q

說明：
- 執行全部單元測試、API 整合測試、Streamlit 冒煙測試與產物雜湊防竄改檢查。
