# 10 評估指標參數手冊

本文件彙整「商業損失評估與評估指標」核心參數。本專案破產預測具有「非對稱成本」特性（漏報一家破產企業的損失遠大於誤報正常企業的調查費用），所有指標設計均圍繞商業決策。

---

### 非對稱錯置成本比率與敏感度
- 登錄表 ID：CFG_COST_FN, CFG_COST_FP, CFG_COST_FN_SENSITIVITY_LIST
- 白話意義：漏報與誤報的罰款比例。假定誤報一家正常企業去調查的成本為 1（`COST_FP=1.0`），漏報一家破產企業導致呆帳的損失為 20（`COST_FN=20.0`），即 20:1 的非對稱成本。敏感度清單 `[10.0, 20.0, 50.0]` 測試不同損失比率下的總預期成本。
- 各模型／各處的設定：

| `CFG_COST_FN` | 全域 config | `COST_FN` | `20.0` | 1.0 ~ 100.0 | `bankruptcy/config.py:39` | 可在 lab 安全調整 |

- 調大／調小會怎樣：
  - 調大 `COST_FN`（例如從 20 調至 50）：【一般經驗，未經本專案驗證】（lab_06，已完成：見 labs/README.md）漏報代價劇增，使較佳決策工作點強烈向高召回率（R95、R100）移動，即使預警名單變長，高召回率依然能降低總期望損失。
  - 調小 `COST_FN`（例如 5 或 10）：【一般經驗，未經本專案驗證】（lab_06，已完成：見 labs/README.md）漏報代價變輕，高預警比率帶來的調查成本佔比上升，較佳工作點向 R80 移動。
- 風險與陷阱：若誤用對稱成本（1:1，如純 Accuracy），模型只需全部猜正常即可達成 96.8% 正確率，但商業上將承擔全部破產呆帳。
- 如何安全實驗：呼叫 `bankruptcy/src/metrics.py:127` 的 `compute_expected_cost` 計算自訂成本矩陣（lab_06，已完成：見 labs/README.md）。
- 已知限制或矛盾：20:1 為金融徵信領域常用之典型假設（專案未記載選擇理由）。

  - 調小配額（例如 1.5 倍或 3 倍，僅調查 4.8%～9.6% 企業）：【一般經驗，未經本專案驗證】（lab_06，已完成：見 labs/README.md）對演算法排序能力要求極度嚴苛，能強烈突顯出集成模型在 Top 排序上的優勢。

- 已知限制或矛盾：專案在各實驗中以 AR@0.95 作為第一核心指標。
