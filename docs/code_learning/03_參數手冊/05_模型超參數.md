# 05 模型超參數手冊

本文件彙整五大基準模型（M1 羅吉斯迴歸、M2 隨機森林、M3 極端隨機樹、M4 XGBoost、M5 LightGBM）之核心超參數。

> [!IMPORTANT]
> **超參數事實準則**：
> 1. 本專案在 E2 調參中採用 Optuna 貝氏尋優（TPESampler）。**最佳值是演算法在多維空間聯合搜尋的結果，非單變量對照效果證據**。未做受控單變量對照時，一律標註「專案在搜尋空間內做貝氏最佳化，未做單變量對照（專案未記載選擇理由）」。
> 2. M5 存在 F-02 配置生命週期差異（選模與調參啟用列抽樣，固化部署元件 `subsample_freq=0` 停用列抽樣）。
