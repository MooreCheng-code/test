## 二、閱讀與使用守則

### 1. 三級證據體系
本手冊中所有關於「調大／調小會怎樣」的敘述均嚴格標示證據等級：
- **【本專案實測：對照實驗】**：專案確實執行過嚴謹受控對照實驗者（如 E1a 不平衡策略、E1b 相關性過濾、E3 集成對照、E4a 安全邊際、E4b 校準比對、E7a/E7b 敏感度分析），附實驗 ID 與證據產物路徑。
- **【專案設定（未做對照）】**：包含 Optuna 搜尋固化之固化超參數。**Optuna 的調優選定值是聯合最佳化的收斂結果，不是「該單一數值優於其他數值」的因果證據**。
- **【一般經驗，未經本專案驗證】**：機器學習社群之實務經驗與理論推論，供學習者參考，並指引後續實驗探索（標註對應 lab 編號）。

### 2. 安全防護邊界
- **唯讀資產禁止更動**：`bankruptcy/outputs/models/splits.joblib`、`outputs/models/final/` 下之模型物件、以及 `outputs/models/best_params/*.json` 為專案凍結產物，嚴禁修改。
- **實驗隔離原則**：任何參數調整實驗僅限於在訓練資料（5,455 筆）內部進行，產物一律輸出至 `labs/outputs/`，嚴禁污染正式評估環境。
