## 2. 專案 5 分鐘深度技術總覽 (The 5-Minute Technical Overview)

### 2.1 業務痛點與核心指標
在企業信貸與供應鏈風控場景中，企業破產屬於極少數事件（本資料集盛行率僅 3.23%）。若使用傳統 Accuracy，模型即便全部猜「正常」也能得到 96.77% 的帳面準確率，卻會造成全數破產漏抓的嚴重風險。同時，ROC-AUC 在高度不平衡下容易因大量真陰性（TN）稀釋而給出偏向樂觀的評估。 <!-- evidence file="bankruptcy/outputs/tables/audit_summary.csv" where="metric=='bankrupt_count_1'" col="value" expect="220" checks="value=220" derived="220.0/6819.0*100=3.2262795131250915; 100.0-220.0/6819.0*100=96.7737204868749" -->

因此，本專案將核心業務目標錨定為**指定召回率下的預警倍數（Alert Ratio at Recall, AR@R）**，定義為「發出預警的總家數 ÷ 真實破產家數」（$	ext{Alerts} / P$），代表風控團隊為抓出指定比例破產企業所必須耗費的審查人力倍數。 <!-- no-evidence: 定義 -->

原始資料包含 95 個高度偏態與共線性的財務指標（包含 `large_value_columns.csv` 記載之 24 個大值厚尾特徵）。我們建立三道前處理管線： <!-- evidence file="bankruptcy/outputs/tables/audit_summary.csv" where="metric=='feature_count'" col="value" expect="95" --> <!-- evidence file="bankruptcy/outputs/tables/large_value_columns.csv" where="column=='Cash Turnover Rate'" col="max" expect="10000000000.0" checks="max=10000000000.0" derived="24=24" -->

2. 採用 `QuantileTransformer(output_distribution="normal")` 映射至常態分佈，緩解厚尾極值對線性與距離模型的尺度敏感度（`preprocessing.py:312`）。 <!-- code file="bankruptcy/src/preprocessing.py" line=312 symbol="output_distribution" expect="normal" -->

### 2.3 巢狀交叉驗證與超參數搜尋
為防範超參數搜尋中的選擇性樂觀偏差，專案實作外層 5 折 × 3 次重複 = 15 次外層評估。在每一外層折的訓練集內部，切分 3 折內層 CV 進行 Optuna 貝氏最佳化：
- E2a 內層調參試驗次數配置為：M1 為 25 次，M2、M3、M4、M5 各為 40 次（`tune.py:502-506`）。 <!-- code file="bankruptcy/src/tune.py" line=502 symbol="M1" expect="3 if quick else 25" --> <!-- code file="bankruptcy/src/tune.py" line=503 symbol="M2" expect="3 if quick else 40" -->

## 3. 十大高頻技術追問與深層回答 (Top 10 Technical Follow-ups)

### Q1. 為何不以傳統 Accuracy 或單純 ROC-AUC 作為驗收指標？
- **結論**：極端不平衡情境下 Accuracy 存在全數漏抓破產的盲猜陷阱，而 ROC-AUC 易因海量真陰性稀釋而高估排序能力，專案採「排序指標 PR-AUC」與「運作指標 AR@R」雙軌驗收。
- **證據**：【本專案實測，附證據】在盲測集上，未調整門檻時模型可獲 96.77% 表面 Accuracy，但破產召回為 0.00%（`06_解答.md:Bug03` 實測落差達 96.50%）；ROC-AUC 達 0.9621 呈現高分，而實質反映少數類權衡之 PR-AUC 為 0.5676。運作指標上，在 $R=0.90$ 下 AR 為 7.66x（發出 337 家預警捕獲 43 家破產），反映每捕獲 1 家破產需審查 7.84 家企業之實質作業負擔。 <!-- evidence file="bankruptcy/outputs/tables/audit_summary.csv" where="metric=='bankrupt_count_1'" col="value" expect="220" derived="100.0-220.0/6819.0*100=96.7737204868749; 0.0=0.0" --> <!-- evidence file="docs/code_learning/lab_snapshots/bugs_summary.csv" where="bug_id=='bug_03'" col="delta_mean" expect="0.965000" checks="buggy_mean=0.965000; clean_mean=0.000000" derived="delta_mean*100=96.5" tol="0.01" --> <!-- evidence file="bankruptcy/outputs/e6/e6_ranking_metrics.csv" where="model=='E_A' and metric=='roc_auc'" col="point_estimate" expect="0.962138" checks="point_estimate=0.962138" tol="0.001" --> <!-- evidence file="bankruptcy/outputs/e6/e6_ranking_metrics.csv" where="model=='E_A' and metric=='pr_auc'" col="point_estimate" expect="0.567586" checks="point_estimate=0.567586" tol="0.001" --> <!-- evidence file="bankruptcy/outputs/e6/e6_operating_points.csv" where="group=='E_A' and operating_point=='R90'" col="alerts_count" expect="337" checks="target_recall=0.9; positives_caught=43; total_positives=44; alert_ratio=7.659091" derived="alerts_count/positives_caught=7.837209302325581; 1=1" tol="0.01" -->

### Q3. 為何必須採用巢狀交叉驗證（Nested CV）進行超參數調優？

### Q6. 模型成對比較為何採用 Nadeau-Bengio 修正檢定而非傳統 t 檢定？
- **結論**：K 折交叉驗證中各折訓練集高度重疊（重疊率達 $(K-1)/K = 80\%$），破壞了樣本獨立同分佈假設，傳統 t 檢定會膨脹型一錯誤（Type I Error）。
- **證據**：【理論推導】Nadeau-Bengio (2003) 提出方差修正因子 $1/J + \\frac{n_{\\text{val}}}{n_{\\text{tr}}} = 1/15 + 0.25 \\approx 0.3167$。在 E3b 候選模型成對評估中，若使用傳統檢定，許多演算法差異之 p 值會被虛假低估；引入 NB 修正後，$E_A$ 對單模型 M3 之差異檢定 $p_{\\text{NB}} = 0.5771$（調整後 $p_{\\text{Holm}} = 1.0$），95% CI [-0.0965, 0.0559] 涵蓋 0，反映兩者無顯著差異。 <!-- evidence file="bankruptcy/outputs/tables/e3b_ensemble_vs_single_paired.csv" where="candidate=='E_A' and comparison_base=='Single Best (M3)'" col="diff_loss_p_nb" expect="0.577066" checks="diff_loss_ci_lower_nb=-0.0965; diff_loss_ci_upper_nb=0.055923; diff_loss_p_nb=0.577066; diff_loss_p_holm=1.0" derived="15=15; 0.25=0.25; 1/15=0.06666666666666667; 1/15+0.25=0.31666666666666665; 95=95" -->
- **限制**：【一般經驗，未經本專案驗證】Nadeau-Bengio 修正較為保守，在樣本量有限且折數較多時檢定力相對較低，難以檢出微小之真實模型改進。

## 5. 誠實限制清單 (Honest Limitations Checklist)

1. **樣本規模限制**：盲測集僅包含 44 家破產企業，儘管捕獲率達 97.73%～100.00%，但統計檢定力受樣本量限制，95% Clopper-Pearson 區間存在一定跨度。 <!-- no-evidence: 限制說明 -->
2. **單一資料集邊界**：本專案所有實證均基於台灣企業破產資料集（6,819 筆），尚未取得跨市場或不同景氣循環之外部資料集驗證。 <!-- no-evidence: 限制說明 -->
3. **高召回伴隨審查成本**：在 $R=0.90$ 工作點下，精準度為 12.76%，意味著約 87.24% 的預警為誤報。專案初期個人設定之 1.5 倍預警目標未能達成，在 3.23% 盛行率下追求高召回必然伴隨較高之風控審查人力。 <!-- evidence file="bankruptcy/outputs/e6/e6_operating_points.csv" where="group=='E_A' and operating_point=='R90'" col="alert_ratio" expect="7.659091" checks="alert_ratio=7.659091; precision=0.127596" derived="100-precision*100=87.2404; 3.23=3.23; 1.5=1.5" -->
