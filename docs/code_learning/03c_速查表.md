## 三、速查表調校指引與安全守則

1. **嚴守訓練折隔離原則**：任何參數調整、特徵縮放、相關性過濾與門檻計算，必須嚴格呼叫 `bankruptcy/src/pipelines.py` 與 `bankruptcy/src/cv.py` 封裝之管線，**嚴禁在包含測試集（`test_idx` 1,364 筆）的資料上執行任何擬合**。
2. **多維調參之因果界定**：Optuna 在 E2b 搜尋出之超參數最佳值為聯合空間的最優配置，不代表該參數在單變量實驗中必然優於其他數值；進行自訂實驗時，應固定其餘參數後做受控單變量對照（可參考 `labs/lab_map.csv` 各規劃模組）。
3. **安全邊際與達標率驗證**：若在自訂資料上重新尋找門檻，切忌僅以訓練集完美經驗門檻為準，必須依據 `bankruptcy/src/thresholding.py:440` 的多折達標率檢驗機制，選定具有足夠泛化覆蓋能力的邊際 $m$。
