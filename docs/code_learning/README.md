# 《企業破產預測專案》程式碼學習資料包：一頁式索引 (`README.md`)

> [!NOTE] 本資料包為《企業破產預測專案》（Bankruptcy Prediction Project）之全套程式碼導讀、參數手冊、數理統計推導與動手實驗環境。詳細學習規劃與環境建置請參閱 [00_讀我_學習路線.md](00_讀我_學習路線.md)。

## 1. 建議閱讀順序（三大路徑）

依據讀者的學習目標，本資料包規劃三條建議閱讀路徑：

- **路徑 A：面試速成衝刺（約 2～3 小時）** <!-- no-evidence: 一般經驗 -->
  1. [00_讀我_學習路線.md](00_讀我_學習路線.md)：掌握專案定位、資料規模與核心成果。
  2. [01_專案全貌與架構導覽.md](01_專案全貌與架構導覽.md)：理解管線防洩漏架構與模組職責。
  3. [03c_速查表.md](03c_速查表.md)：速記核心超參數配置與八大實驗結論。
  4. `_drafts/09_面試說明稿.md`：演練第一人稱口語技術講稿與 10 大面試核心 Q&A。 <!-- no-evidence: 一般經驗 -->
  5. [10_已知限制.md](10_已知限制.md)：掌握 F-01～F-04 缺陷分析與小樣本統計邊界。
- **路徑 B：機器學習工程實踐（約 6～8 小時）** <!-- no-evidence: 一般經驗 -->
  1. [00_讀我_學習路線.md](00_讀我_學習路線.md) $\rightarrow$ [01_專案全貌與架構導覽.md](01_專案全貌與架構導覽.md)。
  2. [02_八大實驗主線導讀.md](02_八大實驗主線導讀.md)：深入 E1～E8 實驗設計與成對假設檢定。
  3. [03_參數手冊/](03_參數手冊/01_資料與切分.md)：精讀 10 大主題參數手冊與 37 張模型卡。 <!-- no-evidence: 架構描述 -->
  4. [04_五大基模型深入剖析.md](04_五大基模型深入剖析.md)：研讀 M1～M5 異質基模型之特性與調參空間。
  5. [05_進階技術專題.md](05_進階技術專題.md)：掌握 ECDF 百分位數集成與動態門檻轉移。
  6. [10_已知限制.md](10_已知限制.md)：了解工業級部署之邊界與外推風險。
- **路徑 C：動手除錯與實驗（約 4～5 小時）** <!-- no-evidence: 一般經驗 -->
  1. [06_練習題.md](06_練習題.md)：動手實作 8 道除錯題，學習避開機器學習常見陷阱。 <!-- no-evidence: 定義 -->
  2. [06_解答.md](06_解答.md)：比對修復程式碼與配對差異統計檢定。
  3. [07_小測驗.md](07_小測驗.md)：自我檢驗 10 題核心觀念選擇題與問答。 <!-- no-evidence: 定義 -->
  4. `labs/`：執行 6 支獨立動手實驗腳本（如校準對照、種子擾動與特徵流形）。 <!-- no-evidence: 架構描述 -->

## 3. 驗證工具與執行指令速查

本資料包配備自動化代碼與文件一致性檢查器，確保文件引用之代碼符號、輸出數據與檔案路徑吻合一致：

```bash
# 1. 嚴格證據與數值檢查（嚴格驗證所有 evidence / code / checks / derived 標籤）
python tools/check_code_docs.py --strict

# 2. 參數卡片覆蓋率檢查（檢查 37 張模型卡與 115 個 ID）
python tools/check_code_docs.py --cards

# 3. 完整性語法與術語檢查
python tools/check_code_docs.py --commands
python tools/check_code_docs.py --recipes
python tools/check_code_docs.py --exercises
python tools/check_code_docs.py --glossary
python tools/check_code_docs.py --registry

# 4. 面試講稿自動渲染（由磁碟 CSV / JSON 自動帶入數據）
python tools/render_interview.py
python -m pytest tools/test_render_interview.py -v
```
